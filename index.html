VIBE CODED SH*T

A free, open benchmark for how healthy your codebase really is.

Health means one thing: how safely and cheaply someone with no memory of your code, a contractor or an AI agent, can make a correct change.
Run one command. Get a score. Find out if you shipped software or a vibe.

Run it

What it measures

Six dimensions, 30 parameters, one score out of 100. Each dimension asks a plain question about your repo.

Safety net

Will a change break something without anyone noticing?

Type & static rigor

Does the code tell you what it expects before you run it?

Architecture & boundaries

Can you change one part without reading the rest?

Complexity & maintainability

How much does someone have to read to make one change correctly?

Dependency & security hygiene

Is the code built on parts that are known, current and safe?

Operability & feedback loop

Can someone new set it up, check a change and know they are done?

Four bands

0-39

Vibe-coded

Changes break things without anyone noticing. Nobody, human or agent, can work here safely.

40-59

Fragile

It works, but every change is a gamble.

60-79

Stable

Changes are safe with care and review.

80-100

Agent-ready

An agent with no memory of the codebase can make a correct change and verify it alone.

Run it

Three steps, inside Claude Code.

  1. Add the marketplace.

    /plugin marketplace add Raavn/vibecodedshit.com

  2. Install the plugin.

    /plugin install codebase-health@vibecodedshit

  3. Run it on your repo.

    /codebase-health

With Docker you get a full score you can compare with other projects. Without Docker the skill runs a preview, marked "not comparable".
