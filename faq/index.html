FAQ

What is vibecodedshit.com?

vibecodedshit.com is a free, open benchmark for codebase health. It scores how safely and cheaply someone with no memory of a codebase, such as a contractor or an AI agent, can make a correct change.

What does codebase health mean?

Health is how safely and cheaply someone with no memory of a codebase, whether a contractor or an AI agent, can make a correct change.

How do I get a score?

Run the codebase-health Claude Code plugin. Add it with /plugin marketplace add Raavn/vibecodedshit.com, install it with /plugin install codebase-health@vibecodedshit, then run /codebase-health. In Codex, add it with codex plugin marketplace add Raavn/vibecodedshit.com, install codebase-health from the Plugins Directory, then run $codebase-health. Without a plugin, run npx vibecodedshit scan . in your repository; it runs on your machine and uploads nothing. The Pack is free for an email address.

What does the score measure?

The score covers six dimensions and 30 parameters: Safety net, Type & static rigor, Architecture & boundaries, Complexity & maintainability, Dependency & security hygiene, and Operability & feedback loop.

What are the score bands?

The health score has four bands: 0-39 Vibe-coded, 40-59 Fragile, 60-79 Stable, and 80-100 Agent-ready.

What data is sent?

Scores are sent only with your consent, and you see the exact payload before anything is sent. The repo name is off by default; a hash of the git remote URL is sent instead.

What is the static preview?

Without Docker the skill runs a static-only preview. It is marked not comparable and cannot be submitted.

Who runs vibecodedshit.com?

vibecodedshit.com is run by Peter's team at VCS.

Is there an offer for bad scores?

Vibe-coded and Fragile results on TypeScript-only repos end with an offer of a free, non-binding quote from Peter's team at VCS to fix the codebase. Other repos get no offer.
